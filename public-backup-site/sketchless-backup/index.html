Sketchless Private Backups copies saved Sketchless design data and CAD exports from the owner's Neon project to a dedicated, unshared folder in the owner's Google Drive.

This is an informational website for a private backup tool. It does not offer public accounts, Google sign-in, or access to any backup. Running the tool requires the owner's separate authorization and credentials.

01 / EXPORT

Read the saved data

Dedicated read-only database and object-storage credentials retrieve the application snapshot and its successful CAD exports.

02 / VERIFY

Test a local restore

The archive's manifest, file checksums and SQLite integrity are checked by restoring it into a temporary directory.

03 / KEEP PRIVATE

Upload and check again

The runner uploads to an owner-private Drive folder, downloads the archive to compare SHA-256, and retains eight verified backups.

Why it uses Google Drive

The owner authorizes the Google Drive API permission drive.file so the tool can create its backup folder and upload, read, verify, list and manage its own backup files. It does not request full-drive access or scan unrelated Drive files.

A one-time local browser flow obtains offline authorization. The prepared private GitHub Actions runner can then perform weekly backups without requiring the owner's PC to stay on. Enabling the runner and completing the first cloud upload are separate setup steps; this website is not a live backup-status dashboard.

What a backup contains

An archive contains the Sketchless application database, including saved conversations and design history, and successful CAD artifacts such as STEP, STL, GLB and scene JSON where available. Those records can contain private prompts, designs and application metadata. Runtime configuration files and API keys are excluded from the archive.

Who operates it

This personal project is maintained by the owner of the GitHub account @kevincyril. It is separate from the public Sketchless sample gallery and is not a public backup service.

Contact and control

For help, privacy questions or deletion requests, use the support email displayed on this tool's Google authorization screen. The maintainer's public GitHub profile identifies the project owner. Do not send credentials, backup archives or private design content through public issues or comments.

You can stop the runner, revoke the Google connection, and delete stored backups. Read the privacy policy for the exact data flow, retention and deletion behavior.
